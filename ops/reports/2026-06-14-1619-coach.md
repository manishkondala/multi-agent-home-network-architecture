## Root cause (from the LEARNINGS entry)
Mandated order was violated: edits were accumulated on base A (the unmerged `feat/streaming-fox-one`
branch) with a dirty tree, then the base was moved to B (`main`) via `git stash`/`checkout`.
The stash's diff context assumed fox-one's top-of-file lines that `main` lacked, so `git stash
pop` conflicted. `git pull --rebase` had separately refused because the tree was dirty. Same
root cause: working before branching, and stashing across diverged bases.

## The rule taught (4 points, cross-referenced to docs/LEARNINGS.md 2026-06-14)
1. Get clean first — `git status` clean before any edit; never edit on a dirty tree.
2. Branch before you work — `git pull --rebase` on `main` → `git checkout -b feat/…` → then edit.
   Never persist directives/docs/code while parked on another feature branch.
3. Stash discipline — only stash→checkout→pop across branches sharing the same base; if bases
   differ, re-apply by hand instead of popping.
4. Branch off `main`, never off another unmerged feature branch (unless intentionally building on it).
