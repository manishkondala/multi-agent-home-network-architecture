## Findings (evidence → fix)

1. **jsms restart incident** (report 2225 line 40 "infra (urgent): restore the legacy
   container" → CTO addendum: owner had stopped it manually at 01:33 UTC).
   Watchdog's own data showed `RestartPolicy: always` yet down — the signature of an
   explicit `docker stop` — and it still escalated as urgent restoration. The deeper bug:
   watchdog.md line 14 demanded the legacy container be "Up", a requirement CLAUDE.md had
   already reversed. **Fixed**: watchdog.md now lists all three jsms containers as
   must-stay-stopped and gains a "Stopped-container triage" section (inspect → `last` +
   shell history → classify crashed vs stopped-by-human → human stop means ask the owner).
   infra.md gains the matching "ask, don't revert" rule.

2. **dev.md contradicted standing order #5** ("Heavy builds happen on the Mac",
   "test locally first", local `docker buildx` example) — the exact recipe for a repeat of
   the Docker-Desktop incident (LEARNINGS 2026-06-11 evening). **Fixed**: builds happen on
   the Pi over SSH; too-heavy builds escalate to the CTO (Mac Mini), never the owner's Mac.
   watchdog.md and infra.md also now state all docker/remediation commands are
   `ssh pi-node1 ...` form.

3. **Lost owner directive** (port 2 apps + homepage redesign; recovered into ROADMAP only
   in commit 3d85d48, a day-end salvage). **Fixed**: all four agent files now require
   directives received directly from the owner to be written into `docs/ROADMAP.md`
   immediately.

4. **Guessed metric names** (watchdog.md shipped `pihole_query_*_today`, which the exporter
   never exposed; CTO corrected to `pihole_ads_blocked_today` / `pihole_dns_queries_today`
   in commit 6a03623). Reviewed the fix: correct, includes a verified-on date — approved.
   Generalized in watchdog.md: an empty query result means list real metric names via
   `/api/v1/label/__name__/values`, never report a guessed name. Checked docs/RUNBOOK.md:
   it carries no stale metric names (report 2225's "from the runbook" referred to the agent
   file itself).
